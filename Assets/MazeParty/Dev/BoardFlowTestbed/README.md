# Board Flow Testbed

`BoardFlowTestbed.unity`는 서버나 Relay 없이 보드 턴 흐름, 카메라 전환,
이동, 아이템 선택 UI를 빠르게 확인하는 에디터 전용 씬이다. 플레이어 빌드에는
포함되지 않는다.

## 실행

1. `Assets/MazeParty/Dev/BoardFlowTestbed/BoardFlowTestbed.unity`를 연다.
2. Play를 누르고 탑뷰 → 하강 → 1인칭 전환을 확인한다.
3. 아이템 또는 `USE NO ITEM`을 고른다.
4. 선택 직후부터 WASD로 현재 칸 안을 움직인다. 플레이어 앞의 월드 주사위는
   좌클릭 타격의 물리 임펄스로 밀 수 있다. 주사위를 조준한 채 우클릭하면
   1~12 굴림을 시작한다.
5. D12가 0.65초 물리 텀블과 0.35초 착지 보정을 거쳐 선택된 숫자를 위로 보이는지
   확인한다. 착지가 끝난 뒤 이동 수가 확정되고, 결과 확인 시간 1초 뒤 주사위가 사라지는지
   확인한다. 파란 경계는 통과할 수 있고 검은 경계는
   물리적으로 막힌다. 이동 횟수가 0이 되어도 마지막 칸 안에서는 이동할 수 있다.
6. 아이템을 선택했다면 주사위가 아닌 곳을 좌클릭해 사용한다.
7. 2턴 탑뷰에서 플레이어가 없는 일반 칸 한 곳에 열쇠 상점이 등장하는지 확인한다.
8. 행동 중 Editor Tools를 누르려면 `Tab`으로 마우스 포인터를 해제한다.
   다시 `Tab`을 누르면 1인칭 시점 조작으로 돌아간다.

## Editor Tools

- `FINISH ACTION (ALL ARRIVED)`: 네 플레이어가 모두 도착한 상황을 만들어 행동 단계를
  조기 종료한다.
- `SPEED x1 / x10 / x60`: 긴 타이머 흐름을 빠르게 검증한다.
- `PAUSE / RESUME`: 게임 중 재접속 대기로 인한 전역 정지와 타이머 보존을
  로컬에서 확인한다.
- 미니게임 소개 화면의 `READY / SKIP ALL`: 아직 구현하지 않은 미니게임을
  건너뛰고 결과 표시 후 다음 턴으로 진행한다.

온라인 권한, 좌석 복원, 실제 연결 끊김은 이 씬이 아니라 4개 프로세스로
`OnlineBootstrap`부터 접속해 검증한다.
